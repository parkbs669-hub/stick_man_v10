🎾 새로운 영상 작업 개시 ~ 완성까지의 5단계 워크플로우
[1단계] 인풋 영상 및 캐시 데이터 최초 생성 (최우선)
새로운 유튜브 링크와 만들고자 하는 동작 이름을 정해 터미널에 입력합니다. (처음에는 잔상 등 복잡한 옵션을 다 빼고 아주 단순하게 1회 가동합니다.)

cmd


python tennis_stickman_v10.py "유튜브_쇼츠_링크" 동작이름
이 단계가 완료되면 생기는 것:
동작이름_input.mp4 (원본 영상 다운로드 완료)
동작이름_pose_cache.json (AI의 랜드마크 분석 완료 및 저장)
[2단계] 임팩트 후보 이미지 덤프 (AI 1차 추천)
1단계에서 인풋 파일과 포즈 데이터가 준비되었으므로, 스마트 덤프 도구를 가동해 임팩트 후보 화면들을 자동 캡처합니다.

cmd


python smart_impact_dumper.py 동작이름_input.mp4 동작이름
이 단계가 완료되면 생기는 것:
Downloads/동작이름_candidates 폴더 아래에 AI가 3번/4번 알고리즘으로 추려낸 전후 찰나 이미지 수십 장이 저장됩니다.
[3단계] 사용자의 진짜 임팩트 순간 고르기
생성된 동작이름_candidates 폴더 내의 사진들을 보고, 라켓 면에 테니스 공이 가장 정확히 닿아 있는 이미지 파일명에 적힌 actual_f 뒤의 프레임 숫자 N을 확인합니다.
[4단계] 고른 숫자로 졸라맨 최종 렌더링
3단계에서 고른 정확한 숫자 N을 수동 임팩트로 콕 찝어 입력하고, 스윙 전후 2초에만 잔상이 촘촘히 렌더링되도록 최종본을 만듭니다.

cmd


python tennis_stickman_v10.py 동작이름_input.mp4 동작이름 --strobe --strobe-frames 20 --strobe-step 2 --impact-frame N
[5단계] 최종 오디오 및 BGM 합성
마지막으로 사운드를 합쳐 완제품을 다운로드 폴더에 뽑아냅니다.

cmd


python mix_bgm.py 동작이름
최종 산출물: 동작이름_stickman_with_audio.mp4 (가상 코트 배경 위 졸라맨 노출 ➡ 임팩트 전후 2초간 촘촘한 네온 궤적 ➡ 320번 순간에만 IMPACT! 자막 노출 ➡ 원본 사운드 및 배경음 합본 완성)
이와 같이 **1단계(인풋 영상 및 포즈 캐시 만들기)**를 무조건 먼저 진행해 두신 후, 순서대로 밟아 나가시면 어떠한 영상이든 막힘없이 가장 정확하고 빠른 속도로 결과물을 만들어 내실 수 있습니다!
